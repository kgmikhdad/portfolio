How updates work

This page contains a saved snapshot, not a live connection. Refresh the repository mirror manually with uv run python scripts/refresh_dashboard.py, or run the “Refresh workbook dashboard” GitHub workflow. Download the updated HTML afterward.

Every refresh saves all source tabs, an Excel workbook, a JSON snapshot and source HTML evidence. A failed download preserves the previous complete snapshot. No values are written back to your original Google Sheet.

For live local backend access: uv run python scripts/serve_dashboard.py. Only the local server reads your portfolio; no ledger export is committed to GitHub.
